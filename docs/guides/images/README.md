# 插图清单（Web UI 已暂停）

> **适用版本** ADR-0067（2026-09-17） · **schema** v36 · **最后校对** 2026-09-17

ADR-0067 起 Web UI 暂停，用户入口只保留 CLI。因此当前用户指南不再征集、引用或维护 Web UI 截图，原有截图清单也不属于验收范围。

仓库仍遵守以下边界：

- 不使用 computer-use、OS 级键鼠/窗口自动化或真实桌面会话生成截图；
- 不引入截图或图片处理依赖；
- 不把保留的 `apps/ui` 源码描述成可运行或受支持的产品面。

未来若恢复 Web UI，必须先另立 ADR，恢复 Runtime 契约、安全边界、测试和用户文档，再重新建立与当时实现一致的插图清单；不要复用暂停前的清单来证明新界面。
